# MVC Locadora

Projeto Spring MVC com Thymeleaf adaptado do exemplo de biblioteca para uma locadora de filmes.

O menu tem páginas de filmes, diretores, gêneros, clientes e locações. Os dados são exemplos definidos no `FilmeController`; ainda não há cadastro nem banco de dados.

Para executar, use Java 25 e Maven na pasta do projeto:

```bash
mvn spring-boot:run
```

Abra `http://localhost:8080/` no navegador.
